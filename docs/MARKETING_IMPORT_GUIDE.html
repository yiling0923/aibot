How to import

Add many answers at one time. Write in one language only: the AI fills the other languages. (The same steps are in the panel: Answers, Import guide. The panel can also be shown in Chinese: press 中文 at the top.)
  1. 1
    Set the languages first (once)

    Open Knowledge base → Languages. Choose the country (it sets the main language), tick the languages the merchant uses, and press Save languages.

  2. 2
    Add your entries

    On the Import page there are two ways. Type in a table: type in the cells, or copy cells from Excel or Google Sheets and paste them (click the first cell, then press Ctrl+V). Upload a file: download the example or the blank Excel file, fill it, and upload it.

  3. 3
    Fill each row

    The columns are Entry name (one short name with no spaces, for example deposit_time), Topic (it must exist on the Topics page), Language, Questions (at least 3, with | between them, with the short forms customers really type) and Answer. Write in the main language only: the Language column starts with it, and the AI writes the other languages. If you write another language yourself, give it its own row with the same entry name.

  4. 4
    Check

    The Check step lists every entry and shows what is wrong, for example a missing topic or fewer than 3 questions. Fix it in the table, or leave it and fix it later.

  5. 5
    Import

    The switch Translate the empty languages with AI follows the merchant setting and translates into the languages you ticked in step 1. Then press Import and publish (the entries go live at once) or Import to draft (nothing changes for customers until you publish).

  6. 6
    Check the AI drafts

    In Knowledge base → Table, the texts written by the AI are purple and marked AI draft · check. Read them and fix what you want (the mark goes away). Use the Live switch to turn an entry on or off.

Done. The bot now answers from your new entries.

Tip: a new merchant's bot starts by listening (it is silent and learns from staff replies and old chats). Check Answers, Learning, add the good learned answers to the Knowledge base, publish, and an admin presses Start answering.
