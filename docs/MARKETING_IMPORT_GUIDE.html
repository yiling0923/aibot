How to import

Write in one language only. The AI fills the others. (The same steps are in the panel: Answers, Import guide. The panel can also be shown in Chinese: press 中文 at the top.)
  1. 1
    Set the languages (once)

    Open Knowledge base → Languages, choose the country and tick the languages, then press Save languages.

  2. 2
    Add your entries

    On the Import page, type in the table (or paste from Excel), or upload an Excel file. The example and blank Excel files can be downloaded there.

  3. 3
    Fill each row

    Entry name, topic, at least 3 questions with a | between them, and the answer. Write in the main language only.

  4. 4
    Import

    Press Import and publish to go live at once, or Import to draft to check first.

  5. 5
    Check the AI drafts

    In Knowledge base → Table, read the purple AI draft texts and fix what you want.

Done. The bot now answers from your new entries.

Tip: a new merchant's bot starts by listening (it is silent and learns from staff replies and old chats). Check Answers, Learning, add the good learned answers to the Knowledge base, publish, and an admin presses Start answering.
