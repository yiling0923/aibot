How to write the knowledge base file

The bot answers customers only from what you write here. If it is not in the file, the bot will not guess; it asks once and then passes the customer to a person. So the file is the bot's whole memory.

1. Make the file

Use Excel or Google Sheets. One row = one answer in one language. When done: File → Save as → CSV (UTF-8). UTF-8 is important, or Chinese and Thai letters turn into strange symbols.

Easiest start: open EXAMPLE_KNOWLEDGE_BASE.csv (in the same folder), change the words, keep the first row.

2. The columns

ColumnMust fill?What to writeExample
intent_keyYesA short name for the question, no spaces (use _). Use the same name on every language row of the same answer.deposit_time
topicYesThe big subject. A new subject is created automatically.deposit
languageYesen English, ms Malay, zh Chinese, vi Vietnamese, th Thai, tl Filipinoen
question_examplesStrongly yesHow real customers type this question. Put | between each one. 4 to 8 is good. Include short, lazy and spelling-mistake versions.how long deposit take | depo not in yet | deposit pending
answer_textYesThe reply the customer sees. Facts only. Put it inside quotes "..." if it has a comma."Deposits are credited within 5 minutes."
question_typeOptionalSplits one topic into kinds: time, limit, how, change, hours. Leave empty if unsure.time
entry_typeOptionalanswer (bot replies, default), promotion (current offer, can end on a date), needs_staff (a person must handle it; bot only passes it on, no answer text needed).answer
topic_short_formsOptionalOther words customers use for the topic. Put | between.depo | top up | 充值
merchantOptionalOnly if one file holds several merchants. Otherwise leave out; the file goes into the merchant you picked.LuckyPay

Same intent_key = same answer in three languages.

4. Writing rules (please read)

Do: write real facts (time, amount, steps). Write each question the way customers type it. One topic of one question per row. Keep answers short, 1 to 3 sentences.
Don't: promise things you are not sure of ("always instant"). Put two different questions in one answer. Copy the same example question into two different entries, because the bot then cannot tell which to answer. Leave answer_text empty for normal entries.
Tip: do English first. The bot needs at least the English answer. Add other languages after.

5. Import it

  1. Open the control panel and choose the merchant at the top left.
  2. Go to Import, pick the CSV file.
  3. Read the preview: it shows which entries are new, which will update an old one, and any problems (shown in red). Fix problems in the file and import again.
  4. Press the import button. The entries go into the draft only.
  5. Check a few entries in Knowledge base.
  6. Press Publish. Customers get the new answers only after this. The yellow "Not live yet" bar reminds you.

Importing the same intent_key again updates that entry, so you can fix the file and re-import safely.

6. Before you send the file, check

  • Saved as CSV UTF-8
  • Every row has intent_key, topic, language, answer_text
  • Questions separated with | (not commas)
  • Each entry has at least an English row
  • No private data (real names, numbers, passwords)
