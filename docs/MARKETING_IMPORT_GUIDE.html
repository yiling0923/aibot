How to import

Add many answers at one time. It takes about 5 minutes. (The same steps are in the panel: Answers, Import guide.)
  1. 1
    Get the Excel file

    In the panel, open Import guide or Import and download the example file or the blank file. Open it in Excel.

  2. 2
    Fill it in

    One row for each question and its answer. The columns are intent_key (a short name), topic, language, question_examples (the ways customers ask, with | between them) and answer_text. English is enough: the AI can translate the other languages for you.

  3. 3
    Upload it

    Go to Import, press Upload a file and choose your Excel file. You can also type straight into the table on that page, or paste cells copied from Excel.

  4. 4
    Import it

    Check the list, then press Import. If you see Translate the empty languages with AI, keep it on and choose the languages. Read the translated answers before you publish.

  5. 5
    Publish it

    Press Review and publish in the yellow bar at the top. Customers see the answers only after this.

Done. The bot now answers from your new entries.

Tip: a new merchant's bot starts by listening (it is silent and learns from staff replies and old chats). Check Answers, Learning, add the good learned answers to the Knowledge base, publish, and an admin presses Start answering.
